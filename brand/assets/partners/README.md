# Partner logos

Place the approved **Saudi Vision 2030** logo here as `vision2030.svg` (or `vision2030.png`).
App footers (`.vision2030`) show it automatically and hide the slot while it is missing.
For emails, host a PNG and pass its URL as `{{vision2030_url}}`.

Use only the official file supplied by the Authority or the Vision 2030 program. Do not redraw it.
